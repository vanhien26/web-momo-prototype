Prototype Lab shell for the MoMo prototype store.

## Getting Started

Run the app from this folder:

```bash
npm run dev
```

Open `http://localhost:3000/lab`.

## Notes

- The Lab reads registry data from the shared root `assets/store.js`.
- Legacy HTML demos stay in place and are previewed through same-origin routes.
- Keep `/lab` as the main React entry point for the prototype store.
